# Purpose
This repository contains code and templates to render agreements for the Open Scholarship Champions program at the Simon Fraser University. It is intended to use with outputs of [this application form](https://forms.cloud.microsoft/Pages/ResponsePage.aspx?id=fmfoBInJuUeGGdg9Wl9sZ5UnmKN79CNHrobFkJjJfX9UOUtSNTdQWEo5NlhMRDdFMEdQT1JIREJTNyQlQCN0PWcu).

# How to use it

1. Download the form responses as a CSV file
2. Create a `data` folder and transfer the file to this folder
3. Run the `render.R` script.

## Before running the script

You must have the `tidyverse` and `quarto` packages installed. You must also have the [Vollkorn variable font](https://fonts.google.com/specimen/Vollkorn) on your font book.
